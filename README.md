# Snake Game 🐍

A classic Snake Game built using Python’s Turtle graphics module. Control the snake, eat food to grow longer, and avoid colliding with walls or yourself. The game includes smooth movement, score tracking, collision detection, and increasing challenge as the snake grows.



## Features
Smooth snake movement
Food spawning at random locations
Score tracking system
Collision detection with walls and snake body
Snake growth after eating food
Simple and interactive gameplay



## Technologies Used
Python 3
turtle module
random module
time module



## Controls
Key	                                    Action
↑ Arrow	                                Move Up
↓ Arrow	                                Move Down
← Arrow	                                Move Left
→ Arrow	                                Move Right



## How to Run
Install Python on your system.
Save the file as main.py
Run the program:



## python main.py

## Game Rules
Control the snake using arrow keys.
Eat the blue food to increase your score.
The snake grows longer after eating food.
Avoid touching the walls.
Avoid colliding with the snake’s own body.
The game ends when a collision occurs.
